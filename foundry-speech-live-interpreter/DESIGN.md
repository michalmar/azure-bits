# Frontend design

The page uses the repository's precision demo surface: near-black product
header, white canvas, ink-blue type, low-radius controls, system fonts, and cyan
only for live-state emphasis.

The primary evidence is a two-channel conversation tape. Source speech and
translation share aligned rows, while one cyan timing line moves between them
during capture. This is the only expressive motion and is removed when reduced
motion is requested. Controls stay compact so the transcript remains dominant.
