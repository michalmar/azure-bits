Same app. Governed by the gateway.

A meeting-notes summarizer calls a model directly, then through AI Gateway. The gateway enforces a token cap and a per-key rate limit. When it blocks the large model, the app falls back to the small one and keeps working.

Every call is recorded with the requested and served model, the gateway decision, tokens, latency, estimated cost, and the raw gateway evidence.

    Why the comparison is fair
    
          
    
            Both tiers receive the same input text. Generation settings follow each model's capabilities
            (large: —; small: —). The direct baseline
            calls the same large deployment as the gateway's primary alias. The difference is deliberate and visible:
            the large tier uses the structured prompt (Kontext, Rozhodnutí, Akční položky, Rizika, up to 8 points,
            1000 output tokens); the small tier uses the concise three-paragraph prompt
            (350 output tokens). Cost is estimated from returned token usage and
            configured list prices, not from billing data. Latency is one observation, not a benchmark.
