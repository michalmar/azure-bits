How to read it

Public availability, not announcement hype

Each dot represents a model’s first public availability. Larger ringed dots mark generation-level changes. The two colored lanes share one date axis, making release clusters and direct timing comparisons visible.

The animation is deterministic: the browser player and MP4 exporter render the same frame for the same timestamp. Source links and editorial notes are stored alongside every release in releases.json.
