Vyber workshop. Sleduj agenta.

Agent vybere workshop pro tým. Foundry mu poskytne postup, nástroje a pracovní prostředí — vy nemusíte psát vlastní agent loop.

Jak funguje Copilot harness?
01

Model rozhoduje

Rozumí cíli a vybírá další krok. Samotná textová odpověď ale ještě není hotová práce.

02

Skill učí postup

Verzovaný SKILL.md a Python skript určují, jak načíst nabídky, spočítat cenu a doložit závěr.

03

Nástroje pracují

Čtení souboru, skutečný výpočet v sandboxu, web search a vytvoření reportu. Ne pouze tvrzení, že se to stalo.

04

Harness koordinuje

Microsoft spravuje agent loop, kontext a sandbox. Vaše aplikace pouze spustí agenta přes Responses API.

GitHub Copilot pomáhá upravovat azure.yaml v repozitáři. Za běhu pracuje agent ve Foundry, ne tato lokální Copilot relace. Funkce harnessu je v preview.

Zjišťuji dostupnost dema…

Každé spuštění vytváří novou conversation a může být zpoplatněno. Žádné rezervace ani kontaktování provozovatelů. Limit čekání je 5 minut.

Co má tato ukázka prokázat?

Ve skutečném průběhu hledejte použití skillu, načtení CSV, výpočet pomocí shellu a web search. Příchozí události neobsahují soukromé uvažování modelu. Sandbox je spravovaný službou, ne další vámi vytvářený server.

Průběh nástrojů

Pouze události skutečně vrácené službou. Ne předem připravená animace.

  1. Po spuštění se zde objeví skutečné události z Foundry.
