What this measures

Timings use the backend's monotonic clock: Entra token acquisition, request-to-response headers, headers-to-first text token, text generation, and total elapsed time. Cost uses the response's regular input, cached input, cache-write, and output token counts against current Global short-context retail meters. Network conditions, connection reuse, shared quota, temporary Flex capacity, and Priority ramp-rate or downgrade behavior all affect a run.
