Shared setup & architecture

Every demo in this repository is isolated in its own top-level folder and follows the same authentication, infrastructure, and visual design standards.

Azure CLI profile & local development

Local runs and deployment scripts expect an authenticated Azure CLI session using the repository configuration directories: 

export AZURE_CONFIG_DIR="$HOME/.azure-365"
export AZD_CONFIG_DIR="$HOME/.azd-365"

Managed identity & reader protection

Demo workloads authenticate to Microsoft Foundry, Azure OpenAI, Speech, and Blob Storage with user-assigned managed identities rather than service keys or secrets. Public Azure Container Apps endpoints require single-tenant Microsoft Entra sign-in.

Terraform & scale-to-zero hosting

Infrastructure lives in each demo’s infra/ folder and provisions Azure Container Apps Express in Sweden Central with HTTP scaling from zero to one replica, dedicated ACR, and least-privilege role assignments.
